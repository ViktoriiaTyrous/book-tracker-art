# Book Tracker artwork

Artwork for the **Book Tracker and Reading Log** Google Sheets template by DesyGoods.

`tree/tree0.png` … `tree/tree8.png` are the nine stages of the reading tree. The
spreadsheet picks one of them with a formula, based on how many books have been
finished, so the cherry opens further the more the reader reads.

These files are referenced by every copy of the template that has ever been
sold. Please do not rename, move or delete them.
